# GTD 테러 데이터 분석 — 좌표만으로 무기 유형 분류하기

Global Terrorism Database(GTD) 15만여 건을 전처리하고, 사건이 일어난 **위도·경도만 가지고 그 사건에 쓰인 무기 유형을 분류**하는 KNN 모델을 만든 프로젝트입니다.

> 북경이공대학교 빅데이터 수업 프로젝트 · 개인 작업 · 2026-04

---

## 원래 하려던 것과 실제로 한 것

처음 세운 목표는 "특정 지역의 테러 발생 가능성과 그 지역 테러의 성격을 데이터로 분석한다"였습니다. 수업 실습 범위 안에서 진행하다 보니 거기까지 가지 못했고, 실제로 완성한 건 그 앞 단계인 **"좌표 → 무기 유형 분류"** 하나입니다.

| | |
|---|---|
| 처음 목표 | 지역별 테러 발생 가능성 예측 |
| 실제 도달한 지점 | 좌표로 무기 유형 4종 분류 · 테스트 정확도 68.0% |
| 하지 못한 것 | 위험도 자체의 예측, 시계열 분석, 모델 튜닝·교차검증 |

중간에서 멈춘 상태를 그대로 남겨둔 저장소입니다. 정리하면서 결과를 부풀리기보다, 어디까지 갔고 무엇이 부족한지를 적는 쪽을 택했습니다.

## 데이터

[Global Terrorism Database](https://www.start.umd.edu/gtd/) — 1970~2015년 전 세계 테러 사건 기록.

- 원본 100개 이상 컬럼 중 23개로 줄인 파일을 받아, 분석에 쓸 **11개 컬럼만 선별**해서 로드 (152,252건)
- 무기 유형이 명확한 4종(폭발물 / 총기 / 냉병기 / 화학무기)만 남겨 **130,681건**으로 축소

무기 유형 분포는 상당히 치우쳐 있습니다.

| 무기 유형 | 건수 | 비율 |
|---|---:|---:|
| Explosives/Bombs/Dynamite | 77,755 | 59.5% |
| Firearms | 49,801 | 38.1% |
| Melee | 2,922 | 2.2% |
| Chemical | 203 | 0.2% |

**이 불균형이 결과 해석에서 핵심입니다.** 아래 결과 항목 참고.

## 분석 흐름

**1. 전처리 · 탐색** — [`data_preprocessing.ipynb`](data_preprocessing.ipynb)

- 필요한 컬럼만 로드, `describe()`로 분포 확인
- 수치형 컬럼 간 상관관계 히트맵
- 무기 유형 4종으로 필터링 → 연도별 / 공격유형별 / 무기유형별 집계
- 정제 결과를 `arms_DF_ver2.csv`로 저장

**2. 모델링** — [`knn.ipynb`](knn.ipynb)

- 입력: **위도·경도 2개만** (다른 컬럼은 쓰지 않음)
- 정답: 무기 유형 4종 (Chemical=0, Explosives=1, Firearms=2, Melee=3)
- 8:2 분할(`random_state=20`) → 학습 104,544건 / 테스트 26,137건
- `KNeighborsClassifier` 기본 설정(k=5)으로 학습
- 무기 유형별 좌표를 색으로 구분한 산점도로 지리적 분포 시각화

## 결과

| | 정확도 |
|---|---:|
| 학습 데이터 | 73.3% |
| **테스트 데이터** | **68.0%** |
| 참고: 전부 다수 클래스로 찍었을 때 | 59.5% |

**68%라는 숫자만 보면 그럴듯하지만, 다수 클래스(폭발물)로 전부 찍어도 59.5%가 나옵니다.** 즉 이 모델이 실제로 얻은 것은 찍기 대비 **약 8.5%p**입니다. 좌표 두 개만으로 만든 모델치고는 의미 있는 차이지만, "68% 정확도"를 성과로 내세울 수는 없다고 봅니다.

시각화에서는 무기 유형이 지역별로 뚜렷하게 뭉쳐 있는 것이 보입니다. 모델이 8.5%p를 얻은 것도 결국 이 지리적 군집을 학습한 결과입니다.

예시로 필리핀 루손섬 부근 좌표(15.675, 120.332)를 넣으면 `Firearms`로 예측합니다.

## 한계

정리하면서 확인한, 지금 상태에서 명확한 약점들입니다.

- **평가 지표가 정확도 하나뿐** — 클래스 불균형이 심한 데이터에서 정확도만 보면 판단을 그르칩니다. 클래스별 precision/recall이나 혼동 행렬을 봤어야 했습니다. 특히 화학무기(203건, 0.2%)는 모델이 사실상 한 번도 맞히지 못했을 가능성이 큽니다.
- **레이블을 위치로 부여함** — 데이터프레임을 무기 유형으로 정렬한 뒤 `[0]*203 + [1]*77755 + ...` 형태로 정답을 만들었습니다. 정렬 순서와 개수가 정확히 맞아떨어져야만 성립하는 방식이라, 데이터가 조금만 바뀌어도 정답이 조용히 어긋납니다.
- **하이퍼파라미터를 건드리지 않음** — k값을 바꿔보거나 교차검증을 하지 않았습니다.
- **좌표 스케일링 없음** — KNN은 거리 기반인데 위도(-90~90)와 경도(-180~180)의 범위가 달라 경도 쪽 영향이 더 큽니다.
- **원래 목표와의 거리** — 이 모델은 "여기서 테러가 일어날까"에 답하지 않습니다. "여기서 이미 테러가 일어났다면 어떤 무기였을 가능성이 큰가"에만 답합니다.
